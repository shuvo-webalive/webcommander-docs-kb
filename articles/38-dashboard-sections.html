The Dashboard sections API lets your software read what one tab of the admin dashboard's section tabs shows: order updates and best sellers, content to review, bookings, courses, or blog activity. The one endpoint is available in all seven WebCommander SDKs.

Open the Dashboard sections reference

Common tasks

You want to Use
Read the ecommerce tab Get a dashboard section with section set to ecommerce. It returns order_updates and best_selling_products
Read the content tab Get a dashboard section with section set to content. It returns content_updates and top_pages
Read the bookings or courses tab Get a dashboard section with section set to bookings (needs_attention and upcoming) or courses (new_enrolments, unpaid_orders and popular_courses)
Read the blog tab Get a dashboard section with section set to blog. It returns comments_to_moderate, drafts_to_publish and most_viewed_posts
Read a tab for another period Get a dashboard section with duration such as last_12_months, or with start_date and end_date as YYYY-MM-DD

All endpoints

This one endpoint reads one dashboard tab, at a path that starts with /api/v4/admin/dashboard/sections.

EndpointMethodPath
Get a dashboard section
Returns what one tab of the dashboard's section tabs shows for a period.		GET…/sections/{section}

Good to know

Pass the tab's name as section. section is one of ecommerce, content, bookings, courses or blog. Any other value is rejected with 404, the reason not_found and the message dashboard section not found, with the detail on the field key.

Each tab returns its own fields. Beside section and period, the response has only the fields of the tab you asked for. A field of another tab is not in the response.

  • The period is the one the reports use. duration is last_30_days unless you send it, or start_date with end_date. A bad value is rejected with 400, and a query parameter the call does not know is ignored.
  • Lists can be empty. A period with no best sellers returns best_selling_products as an empty list, and a store without bookings or courses returns empty upcoming and popular_courses lists. content_updates entries have a count of an empty string.
