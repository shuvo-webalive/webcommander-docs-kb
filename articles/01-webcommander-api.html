The WebCommander API lets your own software read and change a store's data: customers, settings, tax, shipping, inventory and more. This article explains what the API is, which tools you can use with it, and where to find the full developer documentation.

Open the developer documentation

Who this is for

The API is for developers building an integration with a WebCommander store, for example syncing customers with a CRM, keeping stock levels in step with a warehouse system, or managing tax and shipping rules from your own tools. You do not need the API to run a store day to day; everything here can also be done in the WebCommander admin.

Two ways to use it

Option Best for
An SDK
Python, JavaScript, PHP, Java, .NET, Dart or Go		 Most integrations. The SDK signs in for you, keeps the access token fresh, retries safely and turns failures into clear errors. Every call is the same in all seven languages.
The REST API directly
Any language, or cURL		 A language without an SDK, or a quick one-off call. You request an access token yourself and send it with each request.

What you can work with

Area What you can do
Customers List, find, create, update and delete customers; export and import them; manage addresses, passwords and store credit.
Page settings The category, product, search result, shopping cart and checkout page settings.
Store settings Site, e-commerce, customer portal, price display, product listing, search, SEO, shipping and animation settings.
Tax Tax codes, rules, zones, profiles, custom profiles, country taxes and the store's tax settings.
Shipping Shipping methods and shipping classes.
Inventory and orders Inventory locations and order flags.
Domain aliases The extra hostnames a store answers on.

Areas with a link have full reference documentation. The others are available in every SDK and their reference pages are being added.

Get started

1Get your API credentials. Your store's client ID, client secret, redirect URI and auth string. Your WebCommander contact can provide them. Authentication explains each one.

2Install the SDK for your language. See Installation.

3Make your first call. The List customers page shows it in every language.

Keep your credentials private

The client secret and auth string give admin access to the store's data through the API. Keep them in environment variables or a secrets manager, never in source code or a shared document.
