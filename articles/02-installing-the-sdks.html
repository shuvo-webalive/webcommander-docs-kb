Each WebCommander SDK is published to its language's package registry, such as PyPI, npm or NuGet, and its source code is public on GitHub. You can install an SDK either way. This article lists the package and repository for each language and what you need. The developer documentation has the full commands.

See the installation guide

Two ways to install

  1. From the package registry. The usual choice: one command adds the SDK to your project, and your package manager handles updates.
  2. From GitHub. Installs straight from the public repository, for example to use a change before it is released.

Install from the package registry

Language Package Command
Python webcommander on PyPI pip install webcommander
JavaScript webcommander on npm npm install webcommander
PHP webcommander/webcommander on Packagist composer require webcommander/webcommander
Java com.webcommander:webcommander on Maven Central Add the dependency to pom.xml
.NET WebCommander on NuGet dotnet add package WebCommander
Dart webcommander on pub.dev dart pub add webcommander
Go github.com/WebCommanderCMS/webcommander-sdk-go/v4 on Go module proxy go get github.com/WebCommanderCMS/webcommander-sdk-go/v4

Install from GitHub

Language Repository How
Python WebCommanderCMS/webcommander-sdk-python pip install git+https://github.com/WebCommanderCMS/webcommander-sdk-python.git
JavaScript WebCommanderCMS/webcommander-sdk-js npm install github:WebCommanderCMS/webcommander-sdk-js
PHP WebCommanderCMS/webcommander-sdk-php Add the repository as a VCS source, then composer require webcommander/webcommander:dev-main
Java WebCommanderCMS/webcommander-sdk-java Clone it, run mvn install -DskipTests, then add the dependency
.NET WebCommanderCMS/webcommander-sdk-dotnet Clone it, run dotnet pack, then add the package from the local folder
Dart WebCommanderCMS/webcommander-sdk-dart dart pub add webcommander --git-url=https://github.com/WebCommanderCMS/webcommander-sdk-dart.git
Go WebCommanderCMS/webcommander-sdk-go Same as the package: Go always installs from the GitHub repository

What each SDK needs

Language You need
Python Python 3.10 or newer
JavaScript Node.js 20.19 or newer
PHP PHP 8.2 or newer and Composer 2
Java JDK 17 or newer and Maven 3.9 or newer
.NET .NET SDK 8.0.100 or newer
Dart Dart 3.5 or newer (included with Flutter)
Go Go 1.24 or newer

Keeping the SDK up to date

If you installed from the package registry, upgrade with your package manager, for example pip install --upgrade webcommander or npm install webcommander@latest. If you installed from GitHub, run the same install command again; for Java and .NET, pull the clone and run mvn install -DskipTests or dotnet pack again.
