The WebCommander SDKs are not published to a package registry such as PyPI, npm or NuGet. Each SDK lives in its own Bitbucket repository, and you need read access to it. Installing one takes three steps:

  1. Clone the repository's development branch. It is the main branch; the default branch does not carry the SDK.
  2. Run one command in the clone to make it usable.
  3. Point your project at the clone. Keep the clone next to your project, because the paths are relative.

See the step-by-step instructions for your language

What each SDK needs

Language Requires Command in the clone
Python uv 0.8.4 or newer (provides Python 3.10 to 3.13) uv sync
JavaScript Node.js 18 or newer npm install
PHP PHP 8.2 or newer, Composer 2 composer install
Java JDK 17 or newer, Maven 3.9 or newer mvn install -DskipTests
.NET .NET SDK 8.0.100 or newer dotnet pack
Dart Dart 3.5 or newer (included in Flutter) dart pub get
Go Go 1.24 or newer go build ./...

Keeping the SDK up to date

Run git pull in the clone. Python, JavaScript, PHP, Dart and Go pick up the change straight away. Java and .NET use a built copy, so run the command in the clone again after pulling. The installation guide has the details for each language.
