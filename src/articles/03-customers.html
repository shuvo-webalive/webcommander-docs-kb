The Customers API lets your software manage a store's customers: find them, create and update them, move them in and out of the store in bulk, and manage their addresses, passwords and store credit. All fifteen endpoints are available in every WebCommander SDK.

Good to know

Use customer_id, not internal_id

Every customer carries two ids. Endpoints take customer_id. Sending internal_id by mistake can return a different customer instead of an error, so always check the record you get back.

New customers cannot sign in until they are active

A customer created without status: "active" is created as awaiting verification and has no usable login, even with a password.

  • Lists return up to 20 customers at a time. Ask for the next page to see more.
  • An export always contains every customer. Its options choose which columns appear, not which customers.
  • A bulk password reset emails the customers. Each customer receives a reset email.
  • An import can partly succeed. Check the number of failed rows in the result.
